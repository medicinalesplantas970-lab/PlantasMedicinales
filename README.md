# NaturalApp

Aplicación web estática de plantas medicinales, preparada para publicar en GitHub Pages. No requiere servidor ni base de datos: usuarios, plantas, favoritos, comentarios y visitas se almacenan en `localStorage` del navegador.

## Uso

Abre `index.html` o habilita GitHub Pages desde la rama que contiene el proyecto.

Cuenta administradora inicial:

- Correo: `admin@naturalapp.local`
- Contraseña: `admin`

El administrador puede crear, editar y eliminar plantas, además de consultar el panel de visitas. Las cuentas registradas son usuarios normales.
